# Birthday Surprise Maker V4 — Surprise Studio

Upload `index.html`, `style.css`, and `script.js` to the root of your GitHub Pages repository.

V4 is a no-code creator interface:
- Basics / Style / Memories / Surprise wizard
- Live phone preview
- 6 themes
- Up to 8 photos
- Local music
- Secret message and reasons
- Floating hearts and confetti
- Save on device
- Text/settings share link
- Mobile responsive

The selected photos/music are kept locally and are intended for the browser/download workflow; they are not embedded in share URLs.
